# 🛒 E-Commerce Sales Analysis

## 📌 Project Overview

This project focuses on analysing E-Commerce sales data to understand sales performance, profitability, customer behaviour, and business trends.

The project uses Microsoft Excel to analyse sales transactions, identify top-performing product categories, compare regional sales, and evaluate business performance using Pivot Tables, charts, and dashboards.

## 🎯 Project Objectives

- Analyse overall sales and revenue performance.
- Identify top-performing product categories.
- Analyse profit and cost across different categories.
- Compare sales performance across regions.
- Understand customer purchasing behaviour.
- Analyse monthly and yearly sales trends.
- Evaluate the impact of discounts on profitability.
- Identify useful business insights for decision-making.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Visualization
- Data Analysis

## 📂 Dataset Information

The dataset contains **5,000 sales records** with 17 columns.

| Product Category | Category of product |
| Region | Sales region |
| Quantity | Number of products sold |
| Unit Price | Price per unit |
| Cost Price | Cost per unit |
| Cost Amount | Total product cost |
| Discount | Discount percentage |
| Payment Method | Payment method |
| Delivery Days | Delivery duration |
| Customer Rating | Customer satisfaction rating |

| Revenue | Total sales revenue |

## 💡 Key Insights

- Electronics generates the highest revenue among the product categories in the supplied pivot summary.
- Clothing is the second-highest revenue-generating category.
- Electronics also has the highest quantity sold in the supplied pivot summary.
- Product category and regional comparisons help identify business performance.
- Customer ratings and delivery days provide additional insights into customer experience.
- Discount and cost analysis help understand their impact on profitability.
